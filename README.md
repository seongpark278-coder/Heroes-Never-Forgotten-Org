# Heroes-Never-Forgotten-Org
501 (c)(3) non-profit organization

A responsive website supporting active-duty personnel, veterans, disabled veterans, their family members, and widows.

## Preview

Serve this directory with any static HTTP server, or open `index.html` in a browser.

## Hosting

The site uses plain HTML, CSS, JavaScript, and SVG. No build step is required. On Vercel, select the Other framework preset, leave the build command empty, and use the repository root as the output directory.

## Donations

The Donate button links to the supplied PayPal payment page. Suggested amounts are informational; the donor chooses the final amount on PayPal. The supplied PayPal SDK is included; embedded hosted-button rendering awaits the matching HostedButtons configuration.

No banking account numbers or credentials are included in this repository.
